How to Encrypt an External Hard Drive on Windows 10 and 11

Whether you are securing sensitive business files or protecting personal backups, encrypting your external hard drive ensures that if it is lost or stolen, your data remains completely inaccessible to unauthorized users.

Editorial Team • Last Updated: May 2026 • 12 min read
Quick Answer

To encrypt an external hard drive on Windows: The built-in method is BitLocker To Go (available on Windows 10/11 Pro or Enterprise). Right-click the external drive in File Explorer, select "Turn on BitLocker," and follow the prompts to set a password. If you use Windows Home edition, or need cross-platform compatibility with Mac, you will need dedicated external hard drive encryption software like Folder Lock or free alternatives like VeraCrypt.

How External Hard Drive Encryption Works

When you plug in a standard external hard drive, anyone with physical access can plug it into their own PC and read every file. Full disk encryption solves this by using algorithms (like AES-256) to scramble the data at a fundamental level. Without the correct password or decryption key, the data appears as meaningless digital noise.

Unlike simply hiding a folder, true encryption software alters the file structure. This means even if someone attempts to bypass Windows permissions, boot from a live USB, or physically remove the disk enclosure to attach it directly to a motherboard, the files remain protected.

What You Need Before Starting

  • The drive: The external hard drive (Seagate, WD, Samsung, etc.) must be plugged directly into the Windows PC.
  • Format check: Ensure the drive is formatted appropriately (NTFS or exFAT usually). Note: Encrypting a drive that contains data is possible, but a backup is strongly recommended in case of power failure during the encryption process.
  • Windows Edition: Check if you have Windows 10/11 Home or Pro. (Press Windows Key + Pause/Break to check).

How to Encrypt an External Hard Drive on Windows

There are two primary approaches to external hard drive encryption: using Microsoft's native tools, or using third-party encryption software. We cover both below.

Method 1: BitLocker for External Hard Drives (Built-in)

Difficulty:

BitLocker To Go is Microsoft's native full disk encryption tool. It is robust and deeply integrated into the OS. However, it is only available if your host PC runs Windows 10 or 11 Pro, Enterprise, or Education.

Step-by-Step Instructions:

  1. Connect the external hard drive to your PC.
  2. Open File Explorer and navigate to "This PC".
  3. Right-click the external drive and select Turn on BitLocker.
  4. Check the box that says Use a password to unlock the drive and enter a strong password.
  5. Choose how to back up your recovery key (Save to your Microsoft account, save to a file, or print it). Do not skip this step.
  6. Select Encrypt entire drive (recommended for drives already in use) or Encrypt used disk space only (faster, for new drives).
  7. Choose Compatible mode if you plan to use the drive on older Windows versions.
  8. Click Start encrypting. Do not unplug the drive until it finishes.

What it's best for

  • Free if you already have Windows Pro
  • No third-party software installation required
  • Highly secure AES encryption

Honest Limitations

  • Not available to create on Windows Home editions
  • Cannot be read natively on a Mac (requires third-party reader)
  • Encryption process can be very slow on large traditional HDDs

Method 2: Dedicated External Drive Encryption Software

Difficulty:

If you use Windows Home, need to share the drive with Mac users, or simply want a faster setup process, dedicated third-party tools are the best route. For this tutorial, we will look at how a tool like Folder Lock approaches the problem.

How it works:

  1. Install the external hard drive encryption software on your Windows PC.
  2. Launch the application and select the Encrypt Files or Protect USB/External Drive module.
  3. The software creates a secure, encrypted "Locker" (a virtual drive) directly on your external hard drive.
  4. You set a master password for this specific Locker.
  5. To protect files, you simply drag and drop them into the Locker. When closed, the files disappear and are encrypted with AES-256.

What it's best for

  • Works flawlessly on Windows 10 and 11 Home
  • Allows you to encrypt specific folders rather than the whole 4TB drive (much faster)
  • Includes portable executable so you can unlock files on a guest PC without installing the software

Honest Limitations

  • If the portable executable is deleted, you must reinstall the software to access the locker

True Portability

The best external hard drive encryption software doesn't lock you to one PC. By keeping the decryption executable alongside your encrypted data, you can plug your external hard drive into any Windows PC, enter your password, and access your files instantly without reinstalling the software.

On-the-Fly Decryption

Instead of manually decrypting a file, editing it, and re-encrypting it, modern tools mount your secure locker as a virtual drive. You open your Word document, type, and hit save. The software handles the AES-256 encryption in the background automatically.

Secure Backup Integrations

Anti-Recovery and Ecosystem Support

Comprehensive tools offer integrated file shredding and history wiping to permanently destroy these unencrypted remnants. Additionally, strong software ecosystems provide companion applications for macOS, Android, and iOS, allowing you to access your protected files seamlessly across your phone and desktop.

Encryption is unforgiving by design. If you are experiencing issues accessing an encrypted laptop hard drive or external disk on Windows 10, review these owner-safe recovery steps.

If you forget your password, you MUST have the 48-digit recovery key. How to find it: Check the Microsoft account linked to your PC (account.microsoft.com/devices/recoverykey), look for a saved .txt file on your internal PC drive, or check your printed physical files. Without the password or the recovery key, the data cannot be recovered by anyone, including Microsoft.

If you know the password: Unlock the drive first. Then right-click it in File Explorer, select "Manage BitLocker," and click "Turn off BitLocker." It will take time to decrypt the data. If using third-party software, open your locker, copy the files out to a normal folder, and delete the locker file.

If you don't know the password: You cannot remove the encryption and keep the data. You must format the external hard drive (using Disk Management), which will securely erase all encrypted data and return the drive to a usable, blank state.

Frequently Asked Questions

Can I use BitLocker to encrypt an external hard drive?
Yes, provided your host computer is running Windows 10 or 11 Pro, Enterprise, or Education. You can use a feature called BitLocker To Go. It cannot be set up from Windows Home editions.
What is the difference between AES-128 and AES-256 encryption?
AES (Advanced Encryption Standard) is the cipher used by the US government. AES-128 uses a 128-bit key, while AES-256 uses a 256-bit key. Both are incredibly secure for consumer needs, but AES-256 is the gold standard for external hard drive encryption software.
Does encryption slow down my PC significantly?
Modern CPUs have hardware acceleration specifically for AES encryption (AES-NI). For day-to-day file transfers to an external drive, the performance impact is usually negligible (less than 5% slowdown).
Can law enforcement decrypt AES-256 encrypted data?
Without the password or the recovery key, no. The math behind AES-256 is mathematically sound. Vulnerabilities usually lie in the user choosing a weak password.
